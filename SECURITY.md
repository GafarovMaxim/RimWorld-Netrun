# Security

This is a RimWorld mod: it runs inside the game, makes no network connections and stores nothing outside the save file.

If you find something that could harm players (for example a crafted save or Def that runs unexpected code through this mod), please do not open a public issue. Report it privately through GitHub: **Security > Report a vulnerability** on this repository, or contact the author through the Steam Workshop page.

Supported version: the latest release on the Workshop and in GitHub Releases.
