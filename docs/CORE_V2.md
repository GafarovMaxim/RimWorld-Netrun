# Core v2: концепт главного экрана терминала

Цель: Core отвечает на три вопроса за секунду: «что со мной (Heat)», «что горит» (события, угрозы, дедлайны), «куда идти дальше» (узлы). Сейчас это только карта с иконкой Heat.

Макет: docs/ui-mockups/7-core-v2.png

## Раскладка (окно 900x720)
1. Верхняя полоса статуса (одна строка): Netrunner (имя), Cyberpod ready/занята, Net online/offline, Netsick, паузы нет (пауза уже сделана в окне).
2. Центр: карта узлов, как сейчас. Core в середине, вокруг Club, Board, Archive, Server room, Studio, Gateway. Линии связи пульсируют, если в узле что-то новое.
3. Core-узел крупнее остальных: кольцо Heat вокруг иконки. Сегменты кольца = 5 уровней (Shadow, Noticed, Tracked, Target, Red zone), закрашен текущий, цвет уровня. Внутри число Heat 0-100. Под ним название уровня и тренд (стрелка вверх/вниз: Heat растёт или остывает, и сколько за сутки).
4. Бейджи на узлах (счётчик в углу): Board = число открытых контрактов, Club = новые контакты/сообщения фиксера, Server room = ИИ требует внимания, Archive = непрочитанные, Studio = готовые записи, Gateway = новые ноды. Красный бейдж = срочно (контракт истекает, ИИ сбежал или бунтует).
5. Правая панель «Сводка» (вместо пустого места), 3 блока:
   - Heat: что даёт текущий уровень (штрафы/угрозы) и что снижает (Scrub the trace, фиксер). Кнопка Scrub the trace прямо здесь.
   - Тревоги: список до 4 строк, самые срочные сверху (рейд через N часов, контракт истекает, ИИ в опасности, Netsick у колониста). Клик ведёт в нужный узел.
   - Ресурсы: Cyberdata (иконка и число), серверы/слоты ИИ, запас чипов.
6. Нижняя строка: Trace-полоса и подсказка последнего события (лента из 1 строки, клик раскрывает журнал последних 10 событий).

## Поведение
- Наведение на узел: подсветка и tooltip с кратким содержимым («Board: 3 контракта, 1 истекает через 12 ч»).
- Клик по кольцу Heat: открывает подробности (история Heat за 7 дней, что подняло, что снизило).
- Узлы без доступа (нет сервера, нет Studio) показываются приглушёнными с подсказкой, что нужно построить.
- Анимация: Core слегка мерцает, чем выше Heat, тем чаще и краснее; на Red zone рамка окна пульсирует.

## Цвета
Как в TERMINAL_UI.md. Heat: зелёный, жёлтый, оранжевый, красный, тёмно-красный по уровням. Board голубой, Gateway синий, остальное по текущей схеме.

2. Панель «Сводка» и тревоги.
3. Лента событий и подробности Heat.

## Клик по центральному узлу: экран «Heat и след»
Открывается как обычный узел (кнопка «◄ Core» назад), это подробности того, что на Core показано одним числом.
1. Шапка: большая шкала Heat 0-100 с пятью цветными зонами, маркер текущего значения, подписи порогов (25/50/75/95).
2. График Heat за 7 дней (линия, зоны фоном). Точки событий на линии: взлом, рейд, Scrub, контракт. Наведение даёт tooltip («Взлом Рынок-34: +1»).
3. «Что даёт этот уровень»: таблица по пяти уровням, текущая подсвечена (эффекты и угрозы каждого уровня).
4. «Что снижает Heat»: Scrub the trace (цена в Cyberdata), сброс через фиксера (цена, скидка за репутацию), естественное остывание (скорость).
5. «Что поднимает»: топ-5 источников за неделю (взломы, rip data, нырки, чёрный брейнданс не поднимает).
6. Trace (шкала следа текущего взлома) и состояние Netsick с описанием.
7. Кнопки: Scrub the trace, Позвать фиксера (ведёт в Club).
Всё читается без действий, из действий только две кнопки.
