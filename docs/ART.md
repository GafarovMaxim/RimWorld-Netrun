# Графика мода: стиль, правила и что ещё нужно

Единый файл по арту. Обновлено 2026-10-14 (сведено из ART_STYLE, ART_REQUESTS, ART_LIST, ART_NEEDED_4/5; сделанное из списков убрано). Что уже есть, смотри `Textures/`; полноразмерные исходники лежат в папке `Hacking Expansion Netrun Art/` (не грузится игрой, остаётся на ПК автора, см. `.gitignore`).

## 1. Техника и папки
- PNG с прозрачным фоном, без текста и тени на земле. Иконки в игре 128 px (мелкие 32/64), предметы 128 px, постройки 2x2 по 256 px, 3x3 по 384 px (в Def через drawSize); гизмо 64 px; исходники можно 1024 и больше, уменьшает сессия.
- Куда класть: предметы `Textures/Things/Item/...`, постройки `Textures/Things/Building/...`, интерфейс терминала `Textures/UI/Netrun/...` (подпапки Cyberspace, Fixers, Frame, Achievements, Menu, Help, Factions). Код ищет файлы по имени при отрисовке, если файла нет, остаётся замена.
- Именование как у готового арта: `Node_*`, `Daemon_*`, `Event_*`, `Icon_*`, `Gizmo_*`, `Tab_*`, `AI_*`, `Heat_*`, `Fixer_*`, `Report_*`, `Dive_*`.
- Частично обесцвеченные шаблоны Maxim (`Templates`): белые и серые малонасыщенные части перекрашиваются кодом в цвет схемы терминала (`NetrunTint`), цветные остаются. Поэтому кнопки рамки, Guide, меню лучше присылать с белыми частями; иконки типов и достижений цветные.
- Папка `Reserved/` с неиспользуемой графикой не грузится игрой, не трогать.

## 2. Стиль

Правила для всех, кто рисует или генерирует графику мода. Повод: первые иконки к CONCEPTS_10 Maxim отклонил («не vanilla-like и не в стиле мода, фракции вообще не то»). Эталоны: моды Vanilla Expanded (Ideology Expanded, Factions Expanded) как ванильная манера, 50 текстур HE, текстуры Netrun.

### Четыре манеры

| Манера | Для чего | Правила |
|---|---|---|
| **А. Ванильный глиф** | иконки фракций (корпорации, команды, наёмники), вопросы и прецепты Ideology, роли, ритуалы | только белый и серый (основа #F0F0F0, тени #B8B8B8–#8C8C8C, контур #000000), потому что игра красит иконку в цвет фракции; сплошной чёрный контур 4–5 px на 128, скруглённые углы, мягкий объём (свет сверху слева), один узнаваемый предмет на 45–55% холста, без фона, рамки, свечения, неона, текста |
| **Б. Ванильная иллюстрация** | мемы Ideology, вдохновения, крупные иконки событий | приглушённая природная палитра (насыщенность ~30), 2–4 цвета плюс белые блики, один яркий акцент допустим (искры), не неон; контур как у глифа; сценка или предмет-символ без фона |
| **В. Вещи мода и HE** | предметы, постройки, гизмо | корпус приглушённый (оливково-серый #6E715E, сталь #8A9099, тёмно-серый #3C3F44), толстый тёмный контур, плоский свет с одним бликом; ОДИН светящийся акцент: бирюза #3FD8E8 (HE и Netrun), у опасного красный #E04050; способности HE плоские двухтонные с чёрным контуром |
| **Г. UI терминала** | ноды, демоны, события сети, кнопки, рамки достижений | неоновые линии (бирюза, золото, зелень, фиолет), восьмиугольные рамки, свечение; живёт только внутри окон мода |

Что какой манерой:

| Что | Манера |
|---|---|
| Иконки фракций (вкладка «Фракции», письма) | А (белая, подкрашивается) |
| Мемы | Б |
| Вопросы, прецепты, роли, ритуалы | А |
| Предметы, постройки | В |
| Гизмо у построек и пешек | В или как у HE |
| Ноды, демоны, события сети, достижения | Г |

Замеры для сверки (средние по иконкам 128 px): VE мемы заполнение 0.45, контур 0.35, насыщенность 33; VE вопросы и фракции насыщенность 0; HE предметы 0.43 / 0.38 / 8; Netrun предметы 0.46 / 0.27 / 19; UI терминала 0.41 / 0.53 / 75 (неон, только внутри терминала).

### Чек-лист перед тем, как отдать иконку
1. Манера выбрана по таблице.
2. Манера А: в пикселях только серое (насыщенность 0).
3. Контур около 4–5 px на 128, сплошной, без разрывов.
4. Нет свечения и полупрозрачного ореола (кроме Г).
5. Предмет занимает около половины холста и читается в 32 px.
6. Рядом с эталоном (VE или HE) на одном листе не выделяется.

Генератор: `tools/gen_icons_v2.py` (функции `tools/netrun_art.py`), прочие: `gen_frame.py`, `gen_achievements.py`, `gen_concepts10_art.py`, `gen_steam.py`.

### Общие промпты для нейросетей
Предметы и постройки: `RimWorld mod game asset, flat cel-shaded vector style, thick black outline, muted military palette (olive green, gunmetal grey, dark charcoal), glowing cyan accents, subtle cyberpunk tech, slightly top-down 3/4 view as in RimWorld, centered, single object, transparent background, no text, no shadow on ground, consistent with existing assets`.
Иконки интерфейса: `game UI icon, bold simple silhouette, thick outline, neon accent on dark, readable at 64 pixels, transparent background, no text`.
Иконки домашних нод: `game UI icon for a cyberpunk network terminal, one centered symbol, thin neon line art with soft glow, 2-3 px strokes, cyan and white lines on transparent background, minimal detail, readable at 64 pixels, same style as a set, no frame, no text, no background plate, no shadow`.

### Известные замечания
- `Faction_Mercenaries` красный, а у фракции задан `colorSpectrum`: игра умножает красный на цвет фракции; по манере А его нужно держать белым (вариант в `ui-mockups/28-icons-v2.png`).
- Иконки v1 к CONCEPTS_10 отклонены; v2/v3 (эмблемы команд: пауки, лисы, пики, крысы, нетопыри, волки; 11 логотипов корпораций; вопросы, роль, мемы) одобрены, «Нейротех» вариант A (нейрон).
- Стиль Ideology «Киберпанк» (мебель, одежда) отменён Maxim: графику для него не рисовать.
- Шрифт: Tektur не используется в игре (только в картинках описания Steam, лицензия OFL).
