# Карта киберпространства v3: концепт

Макет: `docs/mockups/33-cyberspace-map-v3.png`. Источник макета: `black-ice/ui-mockups/33-cyberspace-map-v3-source.html`. Задачи для кода: `docs/TASKS_2026-10-08.md`, раздел C. Правила производительности: `docs/TECH_DETAILS.md` (карта рисуется только пока открыт терминал; цель до 2 мс на кадр).

Термины: **узел** (hub) = точка карты, **нода** (node) = ответвление узла, цель нырка. Подробнее в `TASKS_2026-10-08.md`, раздел «Термины».

## Что не так сейчас

На карте только круглишки: тип ноды, корпорация, выход, цель контракта читаются по цвету и мелкому тексту. Мониторинг Market-81 приходится искать вручную; точку выхода видно только в описании узла; корпорации различаются красным цветом. Нижняя подсказка устарела («needs Discover»).

## Что показываем (цифры на макете)

1. **Маркеры типов нод вместо точек.** Узел рисуется кольцом, вокруг него по окружности маркеры нод: рынок (квадрат с ¤, жёлтый), архив (квадрат с линиями, голубой), корп-хранилище (шестиугольник, красный), заброшенный сервер (треугольник, серый), тёмная биржа (ромб, фиолетовый), корп-ядро (круг со звездой, тёмно-красный). Неизвестные ноды показаны только контуром (серый, 45% прозрачности), после скана или обзора заливаются. Размер узла = размер добычи (как сейчас), но форма и значок = тип. Для узлов с несколькими нодами радиус орбиты больше (28 px против 24).
2. **Точки выхода.** Зелёный порт (квадрат со стрелкой) рядом с узлом и подпись EXIT мелким шрифтом, пока масштаб от 0.8; ближайший к выбранному раннеру выход мигает рамкой. Строка «Exit points» в легенде.
3. **Корпорации.** Мягкая цветная подсветка территории (радиальный градиент 20% непрозрачности и пунктирный контур), у крепости ромб-значок и название заглавными цветом корпорации; узлы, захваченные корпорацией, получают тонкую кайму её цвета. Подпись территории не меньше 11 px, не перекрывает ноды. Нейтральные районы подписываются серым («Market quarter», «Ruins», «Data dump»).
4. **Орбита и Space.** Отдельная полоса сверху с подписью (ORBIT BAND), ромбовидные узлы бирюзового цвета, связи точечные бирюзовые. Каждый орбитальный узел связан с двумя ближайшими узлами нижнего ряда (по расстоянию, не через всю карту). Оффлайн (нет гравикорабля) полоса затемнена, узлы серые с замком. Сейчас длинные связи тянутся через всю карту (скрин 4).
5. **Интерактивная легенда** (левый нижний или правый нижний угол карты, по месту): строки типов нод, выходов, корпораций, цели контракта, тёмных связей и стены. Клик по строке подсвечивает всё такого типа и приглушает остальное (непрозрачность 25%); повторный клик снимает; можно включить несколько. При наведении на строку подсказка с описанием (сколько платит, чем опасно). Состояние только в окне, без сохранения. Старая строка внизу («Size = haul…») убирается.
6. **Цель активного контракта.** Пунктирное янтарное кольцо вокруг узла цели, звезда ★, плашка «CONTRACT · monitor · 2d 4h» над узлом; в панели справа карточка контракта с кнопкой «◎ Show on map» (на макете и на вкладке контрактов в Board): окно переключается на Gateway, камера плавно центрируется, кольцо пульсирует 3 секунды. Нода цели отмечена звездой в списке нод узла.
7. **Больше места.** Расстояние между узлами +30% (генератор `CyberMapGenerator`), масштаб по умолчанию 1.15, окно терминала по умолчанию 110% при достаточном экране. Подписи узлов не пересекаются: при масштабе меньше 0.8 показываются только подписи корпоративных крепостей и узлов с контрактом.

Дополнительно на карте: пульсация вокруг раннера в пути, маршрут раннера подсвечен ярче, пакеты вторжений красные точки на связях, стена (Wall) красным пунктиром с замком и подписью «opens when the first core falls», связи тёмные оранжевым пунктиром.

## Быстрый доступ к киберпространству

- Терминал запоминает последнее состояние окна (экран, выбранный узел, камеру карты) в памяти сессии игры (не в сохранении) и открывается на нём.
- Гизмо капсулы «Cyberspace» открывает терминал сразу на карте, с выбранным раннером этой капсулы.
- Клик по уведомлению киберпространства (раннер добрался, атака, контракт, событие узла) открывает терминал на нужном узле с подсвеченной точкой. Для этого уведомления сети используют письмо особого типа с действием «открыть терминал на узле X».
- Горячая клавиша терминала в настройках (по умолчанию не назначена).

## Защита колонии в домашнем узле

В карточке узла Home (панель справа) вместо программ, демонов и кнопки Dive: блок «Защита колонии»: уровень защиты, список файерволов (`CompFirewall`) с состоянием питания, кнопка изоляции сети (та же, что на рамке, см. TASKS B1), последние 3 вторжения из `IntrusionManager` с результатом. Из постройки гизмо файервола и изоляции убрать.
