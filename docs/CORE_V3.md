# Core v3 и настройки мода

Макеты: docs/ui-mockups/8-core-v3.png (рабочий Core) и 9-core-onboarding.png (до начала игры с сетью).

## Что не так в Core v2
Панель справа выросла в справочник: «что значит уровень», «остывание», «до следующего уровня». Это уже есть на экране «Heat и след». Игроку на Core нужен ответ «что делать сейчас», а не пояснения.

## Core v3
Карта узлов, кольцо Heat и бейджи остаются как есть. Меняется правая панель, три блока сверху вниз:
1. **СЕЙЧАС.** Одна главная рекомендация текстом (по приоритету: срок контракта, просьба ИИ, Heat на пороге, свободная нода, ничего срочного) и до двух быстрых кнопок («Сбросить след», «К доске», «К серверной», «Нырнуть»). Правила и приоритеты в Defs, чтобы править без кода.
2. **ТРЕВОГИ.** До 4 строк с цветной полосой, клик ведёт в узел. Без изменений, но короче тексты.
3. **КОЛОНИЯ В СЕТИ.** Четыре плитки: cyberdata (+продвинутые), ИИ (слоты сервера), чипы (сколько чёрных), группа N/3. Ниже строки: сеть (Вт и онлайн), новые ноды Шлюза, босс-нода. Эффекты Heat убрать с Core: они на экране «Heat и след» по клику на кольцо.
Нижняя строка: Trace, Netsick, сеть, последнее событие (как в задаче про нижнюю строку).

## Core до начала (онбординг)
Пока мир мода не «открыт» (флаг защиты новичка), вместо карты показывается экран «Добро пожаловать в сеть»: чек-лист из четырёх шагов (консоль, капсула, кибер-линк, первый взлом). Выполненные шаги зелёные с галочкой, текущий жёлтый, будущие приглушённые. Как только все выполнены, экран переходит в обычный Core и узлы открываются по одному (Клуб после первого Heat, Доска после первого контакта, Студия после очков и т.д.).
Если Maxim не хочет прятать узлы, чек-лист можно показывать на Core плашкой сверху, а карту оставить.

## Настройки мода: предложение
Сейчас есть: множитель прироста Heat, остывание Heat, акцентный цвет терминала, частота событий ИИ, «Сброс».

Добавить, по группам (заголовки в окне, каждая группа сворачивается):

**Геймплей**
- Режим сложности Heat: Лёгкий / Обычный / Жёсткий (пресет множителей прироста, остывания, цены сброса, штрафов). Отдельные ползунки остаются под «Расширенные».
- Цена сброса Heat: множитель 0.5x–2x.
- Награды нырка: множитель 0.5x–2x.
- Частота событий: ИИ (есть), сетевых атак, событий на карте, событий киберпространства (0 = выключено, 0.5x, 1x, 2x).
- Защита новичка: «Сетевые события только после начала игры с сетью» (по умолчанию вкл).
- Босс-нода: вкл/выкл, интервал в днях.
- Наёмники: вкл/выкл, сила рейдов 0.5x–2x.
- Смерть и необратимость ИИ: можно ли стереть/потерять ИИ насовсем (вкл/выкл «ИИ может сбежать»).

**Интерфейс**
- Акцентный цвет (есть).
- Показывать итоги вылазки (вкл).
- Пауза при открытии терминала (вкл).
- Размер шрифта терминала: маленький/обычный/крупный.
- Анимации терминала (кольцо Heat, свечение): вкл/выкл ради производительности.
- Подсказки по наведению: полные/краткие.
- Письма событий: все / только важные / только в журнал.

**Совместимость и отладка**
- Дев-меню Netrun доступно только в режиме разработчика (по умолчанию так, настройки не нужны).
- «Подробный лог» (вкл только для отчётов о багах).
- Кнопка «Скопировать сведения для отчёта» (версия мода, версия HE, список модов) в буфер.

**Сервис**
- «Сбросить всё» (есть) и «Сбросить группу».
- Ссылки: GitHub, Steam, журнал изменений.

### Что я бы взял в первую очередь
Режим сложности Heat, защита новичка, итоги вылазки, частоты событий по группам, пауза, анимации, кнопка сведений для отчёта. Остальное можно позже.

## Реализовано (2026-10-06)
- Правая панель Core: «Сейчас» (правила Defs/CoreAdvice.xml, класс Netrun.CoreAdviceDef: условие, приоритет, порог, цвет, до двух кнопок; заголовок и текст — label/description, RU в DefInjected), «Тревоги» (счётчик в заголовке, метка !/▲/●, узел справа, клик ведёт туда; добавлены «Турели захвачены» и «Чёрный рынок»), «Колония в сети» (плитки Cyberdata, ИИ, Чипы, Группа; строки Сеть (Вт, онлайн), новые ноды Шлюза, Корп-ядро).
- Онбординг: пока не пройдены 4 шага (консоль связи, кибер-капсула, кибер-линк, первый взлом), вместо карты чек-лист; выполненные зелёные с галочкой, текущий жёлтый, остальные приглушены; кнопка «Пропустить». После — узлы открываются по одному: Клуб и Архив с первым Heat, Шлюз сразу, Доска после первого звонка фиксеру, Серверная с осколком/сервером/ИИ, Студия с очками/записью/чипом. Закрытые узлы тусклые с «?» и подсказкой. Старые сохранения с историей следа пропускают онбординг автоматически. Dev «Network gate: close» возвращает чек-лист.
- Настройки мода: сворачиваемые группы «Геймплей», «Интерфейс», «Отчёты об ошибках»; сложность Heat (Лёгкий 75%/6/150%, Обычный 100%/4/100%, Жёсткий 130%/3/75%: прирост, остывание в сутки, эффективность сброса), «Расширенные» ползунки (ручная правка = «Свой»); частота событий по группам (выкл/0.5/1/2): сетевые атаки и наёмники (вкл. охоту корпов), события на карте, события киберпространства, события ИИ; защита новичка; пауза при открытии; анимации (плавающие ноды Шлюза, свечение узлов Core с бейджем); «Скопировать сведения для отчёта» (версии RimWorld, Netrun, HE, Harmony, настройки, состояние игры, список модов).
