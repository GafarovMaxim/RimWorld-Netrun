# Сетевой терминал: концепт дизайна окон (handoff для кода)

5 октября 2026. Окно в RimWorld рисуется через IMGUI (`Window`, `Widgets`), поэтому спецификация опирается на сетку и токены, которые легко задать в C#. Текущий размер окна 900×720 (сделан в ff785a9).

## Цель
Окно читается с первого взгляда: видно, что важно (Heat, зависимости, просьбы ИИ), что можно нажать и что недоступно. Один визуальный язык для всех вкладок.

## Сетка и размеры
| Токен | Значение | Где |
| --- | --- | --- |
| `win-w`, `win-h` | 900×720 | окно (min 800×600) |
| `pad` | 12 px | внутренний отступ окна |
| `gap-s / m / l` | 4 / 8 / 16 px | между элементами / карточками / секциями |
| `tab-h` | 44 px | высота ряда вкладок |
| `tab-icon` | 32 px | иконка вкладки |
| `row-h` | 32 px | строка списка |
| `btn-h` | 40 px | кнопки действий |
| `card-radius` | 0 (RimWorld рисует прямоугольники) | карточки |
| `portrait` | 96 px | ИИ, фиксеры |
| `icon-s / m / l` | 24 / 34 / 48 px | иконки в строках / на кнопках / в заголовках |

Раскладка: сверху ряд вкладок (иконка + подпись), под ним заголовок вкладки (цвет акцента, линия), ниже область со скроллом, внизу строка статуса (Heat, питание, дата следующей смены пула).

## Цветовые токены
| Токен | Цвет | Использование |
| --- | --- | --- |
| `bg-window` | #1c1f1b | фон окна |
| `bg-card` | #262a24 | карточки |
| `bg-card-alt` | #2f342b | чётные строки |
| `accent` | настройка мода (по умолчанию #3fe0ef) | заголовки, выбранная вкладка, линия |
| `ok` | #4fd36a | хорошо (доверие, награда) |
| `warn` | #f0c040 | предупреждение, золото, закреплён |
| `bad` | #e5533d | опасно (голод, провал, стирание) |
| `purple` | #a070e0 | сопроцессор |
| `muted` | #8b9183 | вторичный текст, неактивное |
| `text` | #e6e8e0 | основной текст |

Правило: цвет всегда сопровождается текстом или иконкой, не только цветом (для дальтоников).

## Типографика
Три размера: заголовок (GameFont.Medium), основной текст (GameFont.Small), мелкий (GameFont.Tiny). Выбор шрифта: пока нельзя (нужен AssetBundle), но можно настроить масштаб текста 90/100/115% в настройках мода.

## Компоненты
| Компонент | Варианты | Заметки |
| --- | --- | --- |
| Вкладка | обычная, выбранная, с бейджем | бейдж: число событий (ИИ просит, контракт горит) |
| Карточка | нейтральная, сервер (accent), сопроцессор (purple), носитель (ok), тревога (bad) | цветная полоса слева 4 px, рамка 1 px |
| Шкала | доверие, голод, Heat | толщина 14 px, число справа, цвет по порогам |
| Кнопка | основная, вторичная, опасная, неактивная | неактивная: бледнее, причина в подсказке |
| Бейдж статуса | активен, спит, изоляция, сбегает | текст + иконка |
| Заголовок раздела | с числом | линия под заголовком |
| Значок булавки | закреплён | вместо текста [Pinned], gold, 20 px |
| Иконка архетипа | цвет по личности + иконка | на карточке ИИ слева от имени |

## Состояния
| Элемент | Состояние | Поведение |
| --- | --- | --- |
| Кнопка | наведение | подсветка +10%, курсор |
| Кнопка | неактивна | текст muted, tooltip с причиной |
| Строка списка | наведение | фон `bg-card-alt` |
| Карточка ИИ | просьба активна | золотая рамка, значок «!» |
| Вкладка | есть событие | бейдж с числом |
| Окно | питание консоли пропало | серая плашка сверху «Нет питания», кнопки неактивны |

## Крайние случаи
- **Пусто:** серый текст по центру с подсказкой («Нет ИИ. Построй сервер и пробуди осколок»). Всегда с кнопкой следующего шага, если она есть.
- **Много элементов:** скролл, заголовки разделов закреплены.
- **Длинный текст:** обрезка с «…» и tooltip с полным текстом; перевод на русский длиннее, поэтому кнопки не фиксируем по ширине текста.
- **Мало места (экран 1366×768):** окно ужимается до 800×600, портреты 64.
- **Клик вне окна:** закрывает окно (твоя просьба).

## Вкладки и их содержимое
1. **Обзор.** Heat крупно (шкала, уровень, значок), скорость остывания, что даёт уровень, бейдж «рейд скоро». Справа: питание сети, число ИИ, активный контракт.
2. **Журнал.** Таблица событий, фильтр по типу (взлом, фиксер, ИИ, атаки), цвет строки по важности.
3. **Фиксеры.** Карточки (портрет, имя, специализация, черта, репутация-шкала, булавка), кнопки «Позвонить», «Сбросить Heat», «Магазин».
4. **Контракты.** Активный контракт сверху (прогресс-бар «сдано N из M», срок), ниже доступные.
5. **ИИ.** Три раздела: сервер, сопроцессоры, носители. Карточка: портрет, имя, архетип (цвет и иконка), статус, доверие и голод, кнопки.
6. **Брейнданс («Студия»).** Записи, библиотека, зависимость, рынок.
7. **Киберпространство.** Граф нод слева (крупно), панель выбранной ноды справа (защита, награда, кнопка «Нырнуть»).

## Доступность
- Весь важный текст контрастность не ниже 4.5:1 к фону карточки.
- Все иконки с tooltip.
- Закрытие по Esc и по клику вне окна.
- Вкладки переключаются Tab / Shift+Tab (если реализуемо в IMGUI).

## Что нужно решить
Нужен ли масштаб текста в настройках (рекомендую да) и стоит ли вынести цвета в настройки полностью (достаточно одного цвета акцента, остальное фиксировано).
