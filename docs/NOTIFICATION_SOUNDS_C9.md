# C9: звуки уведомлений (список для настройки «все / только важные / выключить»)

Источник: обход кода (помощник Haiku), 183 события: 105 сообщений (Messages.Message), 60 писем (LetterStack), 18 прочих. Названия ванильных звуков (Message_Good, LetterArrive и т. д.) даны по памяти и не проверены в игре. Собственные звуки мода — `NR_<Pack>_<id>` через `NetrunSound.Play`; в 32 местах они звучат вместе с сообщением или письмом, в 12 — сами (без сообщения).

## Предложение по настройке

Один выпадающий список в Настройках, «Звуки уведомлений Netrun»:
- **Все** — как сейчас.
- **Только важные** — звучат события уровня «Важное» (ниже). Остальные сообщения и письма Netrun приходят без звука; собственные NR-звуки уведомлений для них тоже не играют.
- **Выключить** — ни одного звука уведомления Netrun; остаются звуки действий игрока (клики, нырок, ввод) из выбранного звукового пакета.

**Как реализовать (для Плотвы).** Звук уведомления в ванили идёт из типа сообщения/письма, поэтому: (1) все собственные `NetrunSound.Play(...)` в паре с сообщением оборачивать в `NetrunSound.Notify(id, importance)`, который проверяет настройку; (2) для ванильного звука Netrun-сообщений использовать общий помощник `NetrunNotify.Message(text, type, importance)` вместо прямых `Messages.Message`/`ReceiveLetter` (183 места, делать по группам, сначала «Важные»); приглушение ванильного звука письма — через `LetterDef.arriveSound` копию `NR_LetterQuiet` с пустым звуком. Звуки действий игрока (`Dive_*`, `UI_*` при кликах) настройка не касается.

## Критерии важности

- **Важное:** угроза, потеря, риск колонии (вторжение, побег ИИ, предательство, Heat Target+/Red, потеря капсулы/линка, провал контракта, налёт), крупный выигрыш (завершённый контракт, пробуждение ИИ, коллапс корпорации), всё, что требует решения (выбор события ИИ, выбор новости).
- **Обычное:** результат действия игрока, которое он только что сделал (принятие контракта, шаг карты, перенос ИИ, правка чипа), положительные побочные находки, изоляция, пинг.
- **Фоновое:** повторяющиеся справочные сообщения (отчёты ИИ, «заголовок добавлен», смена ротации, пересчёты).

«Только важные» = важные; обычное и фоновое молчат.

## Обычные события (звучат только в режиме «Все»)

Принятие контракта (UI_Confirm), вызов фиксера, сброс Heat, поставка (UI_Confirm), отказ сделки (UI_Deny), найденные в нырке награды (исследование, услуга, фавор, чип, демон), бонус-данные капсулы, карта (подключение, узел достигнут UI_Hack, пинг, стена найдена, угроза замечена), изоляция вкл./выкл., ловушка-приманка, отражённая атака, перенос ИИ (сопроцессор, загрузка), кормление ИИ (AI_Feed), выполненный запрос ИИ (AI_Fulfilled), запрос ИИ выдан (AI_Request), квест ИИ, правка и запись брейнданса, воздействие корпораций на репутацию, ваниловые письма об инспирации и квестах.

## Фоновые события (звучат только в режиме «Все», при желании можно сделать беззвучными всегда)

Заголовок добавлен (UI_Notify), Heat снизился (UI_HeatDown), ротация фиксеров, отчёт ИИ (AI_Chime/AI_Echo), «ИИ усыпает», трейт раскрыт, прогноз ИИ, событие ИИ отменено/отложено, диагностика/настройки скопированы, звук смены пакета.

## Исключено

Звуки действий игрока (клики, наведение, ввод, открытие экранов, шаги нырка Dive_Move/Back, Scan, Hack, Download, ICE): не уведомления, настройка их не меняет. Отладочные сообщения (`NetrunDebugActions.cs`).

## Замечания

- Типы сообщений в ваниле: ThreatBig не используется нигде; 2 сообщения ThreatSmall и 9 писем ThreatSmall можно ужесточить в «Важное» (так и сделано выше).
- Письмо о квесте ИИ и инспирации идёт из ванильных путей: управлять звуком можно только через `LetterDef` копию; пока оставить как есть (6 мест).
- Новые события добавлять в этот список вместе с классом важности (`NetrunNotify.Message(..., importance)`).
