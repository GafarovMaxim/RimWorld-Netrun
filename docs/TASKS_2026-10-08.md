Если шейдер недоступен в 1.6 без бандла, запасной путь: один раз при загрузке (и при смене схемы) перекрасить копию текстуры в `Texture2D` на CPU и кэшировать по паре (имя, схема), без перекраски каждый кадр. ## Термины (предложение для Maxim, EN)

Русский: **узел** (точка карты), **нода** (цель нырка), **экран навигации**.
Английский, пара слов:
1. **hub** (узел) + **node** (нода), экран **navigation screen**. Рекомендую: «hub» короткое, в киберпанке привычное, «node» остаётся за целями нырка и читается как в статьях («Node types»).
2. **junction** + **node**: точнее по смыслу узла-перекрёстка, но длиннее для подписей на карте.
3. **site** + **node**: нейтрально, но «site» конфликтует с вездесущим «Site» RimWorld (мировая карта).
Экран на скрине 1 называем **navigation screen**; плитки Club, Board, Archive, Server room, Gateway, Studio называем **sections** (разделами), чтобы они не путались с узлами.
