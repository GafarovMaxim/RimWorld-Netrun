# C18: отладка и ачивки (список для Плотвы)

Составлено по коду (помощник Haiku, облако проверило выборочно). Все 50 действий лежат в `Source/NetrunDebugActions.cs`, категория «Netrun». Явной проверки `Prefs.DevMode` нет и она не нужна: меню отладки RimWorld само доступно только в режиме разработчика. Условие Maxim «все debug-кнопки только при `Prefs.DevMode`» относится к кнопкам в нашем UI (терминал): сейчас таких, кроме надписи «dev: draw» (Dialog_NetTerminal.cs:159–177), нет. Новые кнопки в терминале только за `Prefs.DevMode`.

- **Карта и события:** пересоздать карту, событие сейчас, раннеры прибыли, «почему не срабатывает», случайное событие, именованные события, любой инцидент NR_, шторм данных, заголовок, босс-узел, событийные узлы, узел по типу, локдаун корпорации (`:30–60, :107–119, :242, :256, :361`).

- **Ресурсы и прочее:** выдать ресурсы, тестовый набор взлома, терминал, экономика, чистильщик данных, ворота сети открыть/закрыть, счётчики ачивок только чтение, все демоны (`:22, :103, :122, :136–140, :282, :352–355, :388`).

4. **Все действия называть по шаблону «Раздел: действие»**, чтобы в меню они группировались (сейчас «AIs: …», «Dive: …», «Cyberspace: …» есть, остальные нет).
