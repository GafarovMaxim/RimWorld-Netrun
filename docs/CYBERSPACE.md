# Киберпространство v2: терминал как сеть нод (по Cyberpunk 2020)

5 октября 2026. Заменяет раздел 1 из `phase4-concepts.md`. Идея Maxim: все вкладки терминала становятся нодами одной карты, а ныряют в сеть только через капсулу.

## 1. Главная идея
Терминал это не набор вкладок, а карта «сети» (как архитектура Data Fortress в Cyberpunk 2020). Каждая вкладка это нода. Нода можно открыть, на ней работают окна (фиксеры, ИИ, студия). Дальше от центра лежат внешние ноды, куда можно только нырнуть.

## 2. Два уровня доступа
| Уровень | Откуда | Что доступно |
| --- | --- | --- |
| **Домашний кластер** | сетевая консоль (приказ колонисту) или капсула | свои ноды: Ядро, Журнал, Фиксеры, Контракты, ИИ, Студия |
| **Нырок** | только капсула, колонист с кибер-линком | внешние ноды: поиск, взлом, добыча |

Без капсулы внешние ноды на карте видны серыми силуэтами с подписью «нужна капсула».

## 3. Карта домашнего кластера
Центр: **Ядро** (бывший «Обзор»): Heat, питание, активный контракт. Вокруг на связях:
- **Архив** (Журнал): события следа.
- **Клуб** (Фиксеры): три фиксера, звонок, сброс Heat.
- **Доска** (Контракты): активный и доступные.
- **Серверная** (ИИ): сервер, сопроцессоры, носители.
- **Студия** (Брейнданс): записи, библиотека, зависимость, рынок.
- **Шлюз** (ворота в нырок): список внешних нод.
Связи рисуются линиями; ноды с событиями (просит ИИ, горит контракт) пульсируют цветом.

## 4. Нырок по правилам Cyberpunk 2020
Взято из настольной игры: ходы, архитектура ноды, программы и защита.

**Интерфейс:** навык нетраннера это скорость взлома (в игре уже есть). От него зависит число **сетевых действий за ход** (1 при слабом, до 3 при сильном).

**Архитектура внешней ноды (как Data Fortress):**
| Элемент | Что это | Что даёт |
| --- | --- | --- |
| Вход (Lobby) | первая ноды | безопасно, можно отступить |
| Кодовые ворота (Code Gate) | проверка защиты | нужно пройти для следующих |
| Файлы (File) | архив данных | Cyberdata |
| Узел управления (Control Node) | системы объекта | отключить турели, двери, питание (используется в будущих квестах) |
| Хранилище (Memory Unit) | ценное | осколок ИИ, модуль ядра |
| ЦП (CPU) | сердце ноды | ложный след, захват власти над нодой |
| Выход (I/O Port) | выход | быстрый отход |

**Защита (ICE) по Cyberpunk 2020:** белый лёд (Wall, Gate: ставит проверки) и **Black ICE** (убийцы: бьёт по нетраннеру, вызывает исходы HE: тошнота, кома, блокировка). Наши исходы: «Захват следа» (+Heat), Netsick растёт.

**Ход нырка:**
1. Нетраннер выбирает действие: *Двигаться* на соседний элемент, *Сканировать* (раскрыть скрытые элементы), *Взломать* (обойти ICE), *Скачать*, *Отступить*.
2. Каждое действие тратит сетевое действие. Нода «отвечает»: ICE атакует, растёт след.
3. Ход заканчивается, когда кончились действия; нода делает свой ход.
Это быстро: 5–8 ходов на ноду, окно остаётся внутри терминала, без отдельной игры.

**Программы (по аналогии с 2020):** расходуемые «утилиты» из Cyberdata, ставятся перед нырком:
| Программа | Эффект |
| --- | --- |
| Меч (Sword) | взлом +30%, но больше следа |
| Щит (Shield) | защита от одного удара Black ICE |
| Фальшивка (Decoy) | отводит один удар ICE |
| Призрак (Stealth) | след −50% за ноду |
| Убийца (Killer) | ломает один слой ICE без проверки |

Ядро выдаёт 2 программы в слоте, сопроцессор капсулы добавляет третий слот, ИИ-пассажир даёт собственный бонус.

## 5. Последствия
- Успех: награда ноды, опыт, +Heat по типу ноды.
- Провал или отступление: часть данных теряется, Black ICE бьёт нетраннера (исходы HE), Netsick +.
- Если вышел за время: сеть «выбрасывает», нетраннер на 1 час без сознания (лёгкий исход).
- Сопроцессор капсулы: Netsick ×0.5, Heat ×0.7, третий слот программы.

## 6. Связь с остальным
Всё из `phase4-concepts.md`, раздел 1, сохраняется: ИИ-личности влияют (Призрак: след, Оракул: открывает ноды, Страж: щит), фиксеры дают контракты на ноды, меню строительства «Киберпространство», рейды «Чёрной книги» на высоком следе.

## 7. Этапы реализации
1. **Каркас карты**: окно с нодами и связями, вкладки как ноды (переезд существующих вкладок). Нырка пока нет.
2. **Шлюз и нода-архив**: список внешних нод, простая нода с одним слоем и наградой.
3. **Ходы и ICE**: действия, защита, след.
4. **Программы и слоты**, затем остальные типы нод.
Каждый этап отдельный коммит, играбельный после каждого.
