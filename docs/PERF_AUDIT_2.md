## Новые анимации и фон (риск для производительности)
- Фоновые пакеты и волны Шлюза, бегущие данные по линиям, глитчи: вычислять **только на Repaint** (уже так) и **не создавать объекты в кадре**: пул структур-частиц, один общий таймер реального времени, лимит одновременных пакетов (<=6), отключение при скрытом окне и при `Animations=false`.
- Кольцо Heat: пересобирать текстуру только при смене целого значения (сделано в этапе 1); дальше убрать полную перезапись и менять только вращение/цвет через `GUI.color` и поворот.
- Глитч-эффект кнопок: рисовать две смещённые прямоугольные накладки (без новых текстур), по таймеру 0.1 с.

## План замеров (до правок)
1. Dev-оверлей «Perf»: мс на кадр для OnGUI терминала, число аллокаций (`GC.GetTotalMemory`) за 100 кадров, на экранах Ядро, Шлюз, Нырок, Архив, Киберпедия, Студия.
2. Бюджет: Ядро <= 1.5 мс на кадр, остальные экраны <= 2.5 мс, аллокации в простое < 2 КБ/кадр (цель: 0 на экране без анимации).
3. Сверка до/после для пунктов 1, 2, 6, 7 (ожидаемо самые крупные).
