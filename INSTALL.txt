Hacking Expansion: Black ICE v0.1 (source prototype)

This package contains the complete RimWorld 1.6 mod source and Defs.
A compiled DLL is not included because compiling RimWorld mods requires the game's local managed assemblies (Assembly-CSharp.dll, UnityEngine.CoreModule.dll and 0Harmony.dll), which are not present in the build environment used to prepare this package.

Build on Windows:
  set RIMWORLD_DIR=C:\Program Files (x86)\Steam\steamapps\common\RimWorld
  build.bat

Then enable both Hacking Expansion and Hacking Expansion: Black ICE in the RimWorld mod list.
